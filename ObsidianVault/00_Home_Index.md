# CROW INNOVATIONS Windows System Analysis & Forensics Suite -- Obsidian / Markdown Vault

Run **Run-ForensicAnalysis.cmd** or click **Sync Obsidian Vault (UTIL-01)** in the dashboard to populate this vault with live forensic notes, baselines, stability diagnostics, full BugCheck root-cause analyses, and threat findings from your local Windows system.

> **Note:** Installing the Obsidian desktop app is **100% optional**. All `.md` files in this folder are standard UTF-8 Markdown files that are automatically embedded into `data.js` and rendered inside the Dashboard's built-in **Reporting** Markdown reader (or can be opened in VS Code, Notepad, Typora, MarkText, or Obsidian).
